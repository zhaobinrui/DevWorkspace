# 首次独立发行验收

只有全部项目取得证据后才能将构建标记为 Beta/Release。记录 macOS 版本、机器架构、
App 版本/构建号、发行 ZIP 的 SHA-256，以及每项的结果和问题编号。

## 发行包与 macOS 14

- 在真正运行 macOS 14 的机器或虚拟机上解压经公证的 ZIP，验证 `spctl` 接受、首次启动、
  退出与再次启动。较新系统上的 14.0 Deployment Target 编译检查不能代替此项。
- 确认沿用 `com.zhaobinrui.devspace.workspace`，升级前后的项目清单、Profile 草稿、
  快捷键和外观设置仍可读取；失败时不覆盖已有数据。
- 从已安装旧版升级到新版，验证更新入口指向正确发行版本，下载后仍能通过 Gatekeeper。

## 真实交互

- 仅启动一个 DevWorkspace 实例。菜单栏图标首次点击打开弹窗；再次点击关闭；自动隐藏菜单栏
  收起后关闭；快捷键在图标隐藏时仍可打开/关闭。分别测试浅色、深色和键盘导航。
- 在设置中切换中英文、外观、图标显示与快捷键；确认新控件可点击、焦点可见、VoiceOver
  标签能说明动作，重启后设置保持。
- 用隔离 Node 项目与 `backend` 隔离副本逐项操作 Profile 预览、信任、Compose 启停、
  原生 Java JAR 启停、取消与失败恢复；核对步骤、就绪时间和拒绝停止身份变化进程的反馈。
  `ecm-api` 只做只读来源与信任核对，不连接现有业务数据。
- 记录每条路径的操作步骤、预期/实际、截图或录屏及最终清理结果。未实测的路径保持未通过。
